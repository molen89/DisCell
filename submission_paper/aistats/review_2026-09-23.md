# Reviewer-style change list (2026-09-23)

A critical, reviewer-style read of the **built** manuscript, after adversarial
verification. Work through it top to bottom. Tick a box when you have made the
change, or when you have read the item and decided against it; write the reason
beside the box when you decline.

**Scope.** The files `main.tex` actually inputs: abstract, introduction, method,
conclusion, checklist, and the appendices derivations, rationale and
implementation. The experiments section and the data / calibration / synthetic /
validation / additional-results appendices are commented out of the build and are
**not** reviewed here. No item asks for experiments or results to be added; where
a claim needs evidence later, the item says so and proposes a `\pending{}`.

**How to use.**

- **R. Major**: what a real AISTATS reviewer would hold against the paper. Fix
  before circulating.
- **S. Minor**: correct but local. Fix during the trim.
- **T. Nits**: wording and notation.
- Within each severity, items follow the manuscript in reading order: front
  matter and abstract, introduction, §2.1 … §2.8, conclusion, checklist,
  appendices, then cross-cutting items.
- **Change** gives replacement text or an action. It respects the author
  conventions: no code, file, flag, variable or run names in the article, and no
  measured numbers (model-defining constants are allowed). Numbers and code
  pointers appear only under **Why** and **Evidence**, which are for you.
- Items that duplicate an existing record point to it instead of repeating it:
  `citation_audit.md` (A1–A11, B, C1–C20, D), `docs/paperlog.md` (2026-09-23
  entries), `docs/todo.md` §7 ("Two hops" move) and item 8.11 (invariance
  escalation), `revision_2026-09-17.md` (A/B/C items) and
  `questions_and_issues.md` (numbered items, "Q&I").

**Status.** The verdict from verification, then the lenses that raised the
item (math, code, soundness, positioning, clarity, consistency, domain, critic):

- **confirmed**: the issue and the proposed change both survived checking.
- **partly**: the issue is real; the change given here is the *corrected* one
  from verification, which supersedes the original proposal.
- **contested**: the issue was confirmed, but the two checkers disagreed about the
  fix. Both options are given; you decide.
- **unverified**: the verifier failed. I spot-checked these myself against the
  text or code while writing up; where I did, the evidence says **[checked]**.

**Where each pointer comes from.** Trust these unequally:

- **[TEXT]**: read in the built `.tex` files (line numbers are source lines; one
  paragraph per line, so they are stable).
- **[CODE]**: read in the repository code.
- **[DATA]**: checked against pinned configs, bundles, metrics or the devlog.
- **[PDF]**: read in a cited paper in `submission_paper/articles/` (or its
  extracted text).
- **[WEB]**: from a web search or fetch; read the passage yourself.
- **[MEM]**: from the reviewer's own knowledge, not opened; confirm before citing.

## Reviewer summary

The concerns a reviewer would lead with, in rough order of damage.

1. **The invariance certificate is much weaker than the text says.** The probe
   that "grades" invariance is an unweighted MSE in which the twelve raw image
   principal components carry almost all the variance, so it barely sees
   composition (R20). Its ridge form is additive in type (R21). The nonlinear
   probe that "takes the decision" was run once, on the primary section, under
   an older architecture (R22). The diagnostics are computed on the last epoch
   rather than the accepted checkpoint (R26), and the targets are built on
   held-out cells too (S17). Adversary and probe test only mean-independence
   (R23).
2. **"Stable across κ" does not do the work asked of it.** It only rules out
   leakage of the modelled form (R32). No sampling uncertainty or multiplicity
   control is attached (R33). Two listed readouts are gauge quantities (R31). The
   sweep fits used a different α_z and budget from the reference fits (R28), and
   the κ operating point was read off a criterion biased toward κ = 0 (R24).
3. **Several formal statements are false as written.** "Not the evidence lower
   bound of a single model" is carried over from DisCoVR and is imprecise here:
   both terms bound the same evidence (R16; imprecise rather than false, see the
   adjudication there). The
   per-type translation gauge needs the decoder to see the type (R29).
   "M-estimation target" describes neither a stop-gradient fixed point nor a
   saddle (R17). κ non-identifiability is asserted without an argument (R30).
   The checklist nevertheless claims complete proofs (R35).
4. **Positioning claims novelty that close prior work already has.** MintFlow
   (uncited) has type-conditional adversarial removal of neighbour composition
   (R6). The leakage term is resolVI's neighbour-diffusion term with fixed
   weights (R7). Conditional invariance is equalised odds (R8). The contrast
   with DisCoVR/CSVAE is misstated (R5). The confound itself is published
   (R4).
5. **The paper does not describe what was run.** α_z is half the stated
   bound-equivalent value, and the calibrated weights were set once on one
   section (R18). The reference seed is seed 0 by construction, and one seed was
   excluded under an unstated rule (R25). The seed envelope also redraws the
   split and invariance targets (R27).
6. **The response latent w is priced out.** α_w sits one to two orders of
   magnitude above the bound-equivalent value. Every delivered readout is a
   function of the prior mean, so a reviewer will ask what w buys over a
   node-centric model plus leakage (R19).
7. **The biology is stated loosely.** A response does not make a cell resemble
   its neighbours (R1). The wording is causal (R2). The curated labels encode
   niche state (R9). Labels are colliders (R10). The segmentation mechanism
   described is not the one on these data (R11). Leakage is modelled as
   gene-agnostic and receiver-scaled without saying so (R12). The paper
   contradicts itself on where subclones go (R13).
8. **The paper is about 55% over length before results, and it has no figure, no
   limitations section and heavy repetition** (R37–R40, R34).
